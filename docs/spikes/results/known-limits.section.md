| G1-L1 | A repository created with `git init --separate-git-dir` (its work tree holds a `.git` file naming a git directory elsewhere) is not confirmed by git as a worktree of that clone: `git worktree list` names the git directory, not the work tree, so Wikory treats such a checkout as unregistered and `wikory init` refuses it. Indistinguishable from a hostile directory whose `.git` file names a trusted clone. Fails closed. |
| G6-M1 | Page bodies are indexed from a CommonMark parse (goldmark, no extensions), not from hand-written comment stripping. Text a CommonMark renderer shows is indexed; HTML blocks, raw inline HTML tags, comments, image alt text, link destinations and titles and link reference definitions are not. Consequences: (a) Obsidian-specific syntax such as `%% comment %%` is not recognised and is indexed as text, the safe direction because that text is visible in Obsidian too; (b) text between inline HTML tags (`a <span hidden>x</span> b`) and Markdown paragraphs inside a `<details>` element are text to CommonMark, so they are indexed although a browser may hide them; (c) a visible `[note]: text` line inside a paragraph is indexed because a definition cannot interrupt a paragraph, while the same line after a blank line is a definition and is not; (d) a raw HTML line that opens a second comment after closing the first (`<!-- a --> <!--`) ends its HTML block at the first marker per CommonMark, so the following lines are indexed although a browser would treat them as comment text; (e) a page whose quote, list and indentation prefixes would make the parser's cost quadratic (budget 20 million) is not indexed, with a finding. |
